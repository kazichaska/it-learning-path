# Certifications

> Certifications **open doors** (they get your resume past filters) but **projects get you hired**. Aim for both.

⚠️ Exam codes, prices and content change regularly. Always confirm details on the official vendor page before booking.

## Recommended path for Cloud & DevOps

```
                      ┌──────────────────────────────┐
  Foundations         │ CompTIA A+ (optional, helpdesk route)
                      │ CompTIA Network+ / Linux+ (optional)
                      └──────────────┬───────────────┘
                                     ▼
  Cloud entry         AWS Certified Cloud Practitioner  (or Azure AZ-900)
                                     ▼
  Core ★              AWS Certified Solutions Architect – Associate
                                     ▼
  Specialize          HashiCorp Terraform Associate
                      CKA / CKAD (Kubernetes)
                      AWS SysOps Administrator / Developer – Associate
                                     ▼
  Advanced            AWS DevOps Engineer – Professional
                      AWS Solutions Architect – Professional
                      CKS (Kubernetes security)
```
★ = the single most valuable certification for most cloud job postings.

## Certification overview

| Certification | Level | Covers | Format | Good for |
|---|---|---|---|---|
| **CompTIA A+** | Entry | Hardware, OS, troubleshooting, basic security | 2 exams, multiple choice + simulations | Helpdesk roles |
| **CompTIA Network+** | Entry | Networking concepts, troubleshooting | Multiple choice + simulations | Networking foundation |
| **CompTIA Security+** | Entry–intermediate | Security fundamentals → [study guide](../../06-cybersecurity/security-plus/) | Multiple choice + simulations | Security roles, government jobs |
| **Cisco CCNA** | Associate | Routing, switching, IP services, security, automation | Multiple choice + simulations | Network engineering |
| **AWS Cloud Practitioner** | Foundational | AWS services, billing, shared responsibility | Multiple choice | First cloud cert; career changers |
| **AWS Solutions Architect – Associate** | Associate | Designing secure, resilient, cost-optimized architectures | Multiple choice | Cloud engineer / DevOps |
| **AWS SysOps Administrator – Associate** | Associate | Operating, monitoring, troubleshooting on AWS | Multiple choice | Operations-focused roles |
| **Azure AZ-900 / AZ-104** | Fundamentals / Associate | Azure basics / Azure administration | Multiple choice (+ labs) | Azure-heavy employers |
| **HashiCorp Terraform Associate** | Associate | IaC concepts, Terraform workflow, state, modules | Multiple choice | DevOps / cloud engineer |
| **CKAD** | Intermediate | Deploying apps on Kubernetes | **Hands-on** in a terminal | DevOps / developers |
| **CKA** | Intermediate | Administering Kubernetes clusters | **Hands-on** in a terminal | DevOps / SRE / platform |
| **AWS DevOps Engineer – Professional** | Advanced | CI/CD, automation, monitoring, IaC on AWS | Multiple choice (scenario-heavy) | Senior DevOps |

## How to study for any certification

1. **Download the official exam guide/objectives** and use it as your checklist
2. **One main course** (video or book). Don't collect five courses you never finish
3. **Hands-on labs for every topic.** Build it in a real account (with a budget alert!)
4. **Notes in this repo:** write each topic in your own words
5. **Practice exams** from a reputable source. Read *every* explanation, including for questions you got right
6. **Book the exam** when you consistently score ~80–85%+ on practice tests. A date on the calendar helps motivation
7. After passing: add it to LinkedIn and your resume, and share what you built while studying
